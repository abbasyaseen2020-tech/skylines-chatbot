# استمارة تجميع البيانات — كل ما يلزم لإكمال الحزمة

**املأ هذه الاستمارة مرة واحدة، وتُملأ منها كل المستندات الـ 13 تلقائيًا.**

---

## كيف تستخدمها

1. املأ ما تعرفه **الآن** دون توقف عند الناقص — ضع علامة ⬜ أمام ما تحتاج البحث عنه.
2. ما لا تعرفه، اكتب أمامه **«غير معروف»** أو **«يُستخرج من ……»** بدلًا من تركه فارغًا — الفراغ يُنسى، والملاحظة تُلاحَق.
3. **لا تنتظر اكتمال 100%.** راجع «الحد الأدنى للبدء» في نهاية الاستمارة — بـ 40% من البيانات يمكن إنتاج نسخة قابلة للعرض على المحامي.
4. البيانات المطلوبة من الطرف الثاني موسومة بـ 🔸 — اطلبها منه في **جلسة الحصر**، لا قبلها.

# القسم 3 — الحصر الشامل للمشاريع

**ابدأ هنا.** اكتب **كل** مشروع منذ 2023 دون استثناء وقبل أي تصنيف، ثم صنّفه.

|---|---|---|---|---|---|

| 7 | | | | ☐أ ☐ب ☐ج ☐د | |
| 8 | | | | ☐أ ☐ب ☐ج ☐د | |
| 9 | | | | ☐أ ☐ب ☐ج ☐د | |
| 10 | | | | ☐أ ☐ب ☐ج ☐د | |

**مفتاح التصنيف:**
- **أ** = منتهٍ ومصفّى (أخذت حقك) → ملحق (أ)
- **ب** = مستمر ومشترك → ملحق (ب) + عقد مستقل
- **ج** = آل لخميس مقابل وحدات → ملحق (ج)
- **د** = **متنازع عليه** → قائمة تفاوض منفصلة، لا يدخل الملاحق

> **الخانة (د) هي ساحة المعركة.** افصلها من البداية. الخلاف على مشروع واحد يجب ألا يُعطّل إقفال العشرة الباقين.
